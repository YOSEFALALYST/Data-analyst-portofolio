# 📊 Sales Dashboard – Power BI

## 📌 Project Overview

This project analyzes sales performance using Power BI.

The dashboard includes:

- Total Sales
- Total Profit
- Average Discount
- Number of Orders
- Sales by Month
- Profit by Country
- Sales by Salesperson
- Sales by Category
- Top 5 Products by Sales
